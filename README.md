An invented passport spread for the Republic of Nordhavn, a small lighthouse island nation in the North Sea that does not exist. A program (Python + PIL) draws the open spread: a data page with a portrait and an ICAO 9303 machine-readable zone with correct check digits, and a visas page with a Schengen visa for Norway and arrival and departure stamps from Norway, Iceland and the United Kingdom — one June 2025 journey out and home again, every date after the passport's 14 March 2023 issue and before its 14 March 2033 expiry. The telling detail is the §7 Maritime Code endorsement: the holder may land at any lighthouse station of the Republic.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024 × 1024, under 1 MiB). All type is set by the program; the portrait is a generated photograph shipped in `assets/`, and the fonts (Noto Sans, Noto Serif, DejaVu Sans Mono, all under the SIL Open Font License) are bundled in `assets/fonts/` so the program runs with no network and no system fonts.
